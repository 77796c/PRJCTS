# 💡 Usage Examples

Here are some example conversations you can have with ChatGPT when using the Note Keeper app:

## Creating Notes

**User:** "Create a note titled 'Project Ideas' with the content 'Build a ChatGPT app using the new Apps SDK' and tag it with 'projects' and 'ai'"

**ChatGPT:** Will create the note and return the ID and details.

---

**User:** "Make a quick note: 'Buy groceries - milk, eggs, bread' and tag it 'shopping'"

**ChatGPT:** Creates a note with the content as title or splits it appropriately.

## Viewing Notes

**User:** "Show me all my notes"

**ChatGPT:** Displays all notes in a beautiful card-based grid UI.

---

**User:** "What notes do I have?"

**ChatGPT:** Lists all your notes with summaries.

---

**User:** "Get note abc123xyz"

**ChatGPT:** Shows the complete details of that specific note.

## Searching Notes

**User:** "Find notes about 'projects'"

**ChatGPT:** Searches through note titles and content for the keyword.

---

**User:** "Show me all notes tagged with 'work'"

**ChatGPT:** Filters and displays only notes with the 'work' tag.

---

**User:** "Search for notes containing 'ChatGPT' tagged with 'ai'"

**ChatGPT:** Combines both search criteria to find matching notes.

## Updating Notes

**User:** "Update note abc123 with new content 'Updated project ideas: Focus on ChatGPT Apps SDK integration'"

**ChatGPT:** Modifies the note's content while keeping other fields intact.

---

**User:** "Change the title of note xyz789 to 'Completed Tasks'"

**ChatGPT:** Updates only the title field.

---

**User:** "Add tags 'urgent' and 'important' to note abc123"

**ChatGPT:** Updates the note's tags.

## Deleting Notes

**User:** "Delete note abc123"

**ChatGPT:** Removes the note from storage.

---

**User:** "Remove the note about groceries"

**ChatGPT:** Will first search for the note, then confirm and delete it.

## Advanced Workflows

### Taking Meeting Notes

**User:** "Create a note for today's standup meeting"

**ChatGPT:** Creates a note and prompts for content.

**User:** "Add: Discussed sprint goals, reviewed blockers, planned next steps. Tag it with 'meetings' and 'standup'"

**ChatGPT:** Creates the complete note with proper formatting.

### Organizing Research

**User:** "I'm researching ChatGPT Apps SDK. Create a note with what I find and tag it 'research' and 'chatgpt'"

**ChatGPT:** Creates the note structure.

**User:** "The SDK uses Model Context Protocol, supports custom UI components with React, and requires Node 18+"

**ChatGPT:** Fills in the content.

### Task Management

**User:** "Create three notes for my tasks today:
1. Review PR #123 - tagged 'code-review'
2. Update documentation - tagged 'docs'
3. Fix authentication bug - tagged 'bugs' and 'urgent'"

**ChatGPT:** Creates all three notes at once.

## Tips for Best Results

1. **Be specific with tags**: Use consistent tag names for better organization
2. **Use descriptive titles**: Makes searching and browsing easier
3. **Keep note IDs**: Save important note IDs for quick access
4. **Combine searches**: Use both query text and tags for precise results
5. **Regular updates**: Update notes as information changes

## Voice Commands (ChatGPT Voice Mode)

When using voice mode, try:
- "Create a new note"
- "Show my notes"
- "Search my notes for [keyword]"
- "Delete that note"
- "Update the last note"

## Integration Ideas

While this is a standalone app, you could extend it to:
- Export notes to markdown files
- Sync with external note-taking services
- Add reminders and due dates
- Support note sharing
- Enable note categories/folders
- Add full-text search with ranking
- Support attachments or images

---

*Note: The server stores notes in memory. Restarting clears all data.*
